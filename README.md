El sistema de Cine Facil es un programa que basico que sireve para gestionar las funciones de un cine coomo el ingreso del nombre del cliente
el nombre de la pelicula la cantidad de boletos multiplicados por el costo y al final dar un resumen de todo la reservacion.

Funciones del programa: cambiar_precio

Para hacer la nueva rama hice lo siguiente:

1. crear y canviar a una nueva rama: git checkout -b cambios-nuevos
2. Editar el archivo en este caso es CINE_FACIL.py
3. Hacer un commit de los cambios: 1)  git add CINE_FACIL.py       2) git commit -m "Cambios en el archivo"
4. Subir la nueva rama a GitHub: git push -u origin cambios-nuevos

Lo que aprendi de Git y GitHub es que usando cada uno de ellos puedo llevar un mejor control de las versiones de los
trabajos que voy realizando y tambien si llega el momento de modificarlos tambien les puedo cargar los cambios
